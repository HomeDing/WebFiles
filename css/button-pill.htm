Button implementation for this project

This page is showing the bare CSS to style labels, buttons and inputs.

Buttons

  • Buttons can be given round borders using the pill class on the button.
  • They optionally have leading or training icons.
  • Icons and text must be centered vertically
  • Text is on the same horizontal than the icon.
  • Text does not break into 2 lines when having a space.
  • center of the icon fits to the center of the circle of the button radius.
  • Don't change html only change css. When it cannot be styled by css only, make suggestions.
  • 0.5em space between text and icon
  • #b2 button looks same as #b1

The very simple buttons can be created as 

<button>Submit</button>

Any button with a icon must be created with a <span> element around text: 

<button><svg>...</svg><span>Submit</span></button>
This avoids that the text and icons are too close.
